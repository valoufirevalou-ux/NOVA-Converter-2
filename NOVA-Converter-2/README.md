# NOVA Compress 2.0

Interface simplifiée de compression locale.

## Démarrage
Décompressez le ZIP et ouvrez `index.html` dans Chrome ou Edge.
Une connexion Internet est requise pour charger JSZip depuis le CDN.

## Fonctions
- Ajout de plusieurs fichiers, tous types.
- Création d'une archive ZIP avec compression DEFLATE réglable de 1 à 9.
- Optimisation d'images JPG/PNG/WebP et regroupement dans un ZIP.
- Objectif de taille facultatif pour les images.
- Extraction d'archives ZIP.
- Historique de la session.

## À savoir
La compression ne peut pas garantir qu'un fichier quelconque atteindra 2 Mo. Les vidéos, musiques, images déjà compressées et archives peuvent très peu diminuer. La limite est un objectif, pas une garantie. L'optimisation d'image peut réduire la qualité et convertir les images non-PNG en JPEG. Les fichiers restent traités dans le navigateur ; aucune téléversement n'est effectué.
